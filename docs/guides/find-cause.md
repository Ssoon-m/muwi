# 결과가 이상할 때 원인 찾기

AI가 한 일의 결과가 기대와 다를 때, 기록에서 원인을 찾아 다음 작업부터 같은 문제가 생기지 않게 고칩니다.

고치는 대상은 이번 작업의 순서가 아닙니다. 순서는 AI가 매번 새로 짭니다. 그 아래에 있는 skill, 지침, 훅을 고쳐야 다음에도 효과가 있습니다.

## 1. AI에게 이유 물어보기

무엇이 잘못됐는지 말하고 이유를 물어보세요.

```
브랜치 이름이 틀렸네. 왜 그랬는지 봐줘
```

AI가 `muwi show`로 그 작업의 기록을 읽고 원인을 설명합니다. 직접 보려면 터미널에서 실행하세요.

```sh
muwi show <작업>
```

## 2. 문제가 생긴 노드와 회차 찾기

기록에서 그 일을 한 노드를 찾으세요. 다시 한 노드는 회차별로 나옵니다. 문제가 처음 생긴 회차를 보세요.

```
✓ branch  브랜치 준비  (2회차 · 26s · 세션 t2)
          결과: feature/PROJ-123
          1회차 · 11-22 10:00 · 8s · 세션 t2 · 읽은 skill: 없음 · 결과: feature/x
          2회차 · 11-22 10:32 · 18s · 세션 t2 · 읽은 skill: 없음 · 이미 읽은 상태: branch-rule
```

이 예에서는 1회차에 skill을 읽지 않고 브랜치를 만들었습니다. 2회차에는 그 사이에 읽은 `branch-rule`을 알고 다시 만들었습니다.

## 3. 그 회차의 기록 읽기

"읽은 skill"에 나오는 말로 무슨 일이 있었는지 판단하세요.

| 기록 | 판단 |
| --- | --- |
| skill 이름이 있습니다 | 그 회차를 하는 동안 읽었습니다 |
| "이미 읽은 상태"에 있습니다 | 그 세션이 앞에서 읽어서 내용을 알고 있었습니다 |
| "없음"이고 "이미 읽은 상태"에도 없습니다 | 그 skill 없이 일했습니다 |
| "볼 수 없었음" | 그 세션에서 훅이 실행되지 않았습니다. 읽었는지 알 수 없습니다 |
| "기록 없음(시작과 끝을 한꺼번에 적음)" | AI가 일을 마친 뒤에 시작과 끝을 함께 기록했습니다. "노드 밖에서 읽은 skill"을 같이 보세요 |
| "(서브에이전트)"가 붙어 있습니다 | 서브에이전트만 읽었습니다. 맡긴 세션은 그 내용을 모릅니다 |
| "(확실하지 않음)"이 붙어 있습니다 | 읽을 때 노드 여러 개를 동시에 하고 있어서, 이 노드의 것인지 확실하지 않습니다 |

"볼 수 없었음"이나 "기록 없음"이 나온 회차는 skill을 고치기 전에 기록부터 확인하세요. 훅이 실행되지 않는 이유는 [문제 해결하기](troubleshooting.md#읽은-skill을-볼-수-없었다고-나올-때)에 있습니다.

누가 했는지도 같이 보세요. 서브에이전트와 새 세션은 아무것도 읽지 않은 상태에서 시작합니다. 맡긴 세션이 읽어 둔 skill은 그쪽에 전달되지 않습니다.

## 4. 고칠 곳 정하기

| 기록에서 확인한 것 | 고칠 곳 |
| --- | --- |
| 필요한 skill을 읽지 않았습니다 | 그 skill의 `description`. 언제 읽어야 하는지 드러나게 고칩니다 |
| skill을 읽었는데 규칙을 잘못 적용했습니다 | 그 skill의 내용 |
| 맡은 쪽이 필요한 것을 모르고 일했습니다 | 맡길 때 준 말. 반복되면 skill에 "맡길 때 알려 줄 것"을 적습니다 |
| 계획에 필요한 단계가 없었습니다 | skill이나 지침. 그런 작업의 계획에 꼭 넣을 단계를 적습니다 |
| 하면 안 되는 일을 했습니다 | 그 AI 도구의 권한 설정이나 직접 만든 훅. muwi는 명령을 막지 않습니다 |

새 세션에 맡긴 노드는 카드를 누르면 "맡긴 말"이 나옵니다. 서브에이전트에게 준 말은 기록에 남지 않습니다.

## 5. 고치기

AI가 고칠 곳과 내용을 제안합니다. 승인하면 AI가 그 skill이나 지침이 있는 저장소에 수정 PR을 만듭니다.

문제 지점을 나중에 다시 보려면 표시를 남기세요. 그래프의 카드에 ⚑가 붙습니다.

```sh
muwi flag branch "skill 없이 브랜치를 만듦"
```

## 기록으로 알 수 없는 것

- skill을 읽고도 따르지 않았는지는 기록에 나오지 않습니다. 결과물(커밋, 화면)을 직접 확인하세요.
- skill을 읽지 않았지만 맞게 한 경우도 구분되지 않습니다.
- 대화가 요약(compact)된 뒤에는 앞에서 읽은 skill 내용이 흐려질 수 있습니다. `muwi show`에 요약된 시각이 나옵니다.
