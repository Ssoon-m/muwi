# 서브에이전트와 새 세션 다루기

AI가 노드를 서브에이전트나 새 세션에 맡겼을 때 그래프에서 진행을 확인하고, 새 세션이 요청하는 확인에 답합니다.

노드를 직접 할지 맡길지는 AI가 정합니다. muwi에는 "이런 일은 새 세션으로" 같은 기준이 없습니다.

## 두 방식의 차이

| | 서브에이전트 | 새 세션 |
| --- | --- | --- |
| 실행되는 곳 | 맡긴 세션 안 | 멀티플렉서(예: Herdr)의 다른 터미널 |
| 진행이 보이는지 | 보이지 않습니다. 결과만 돌아옵니다 | 터미널로 보이고 끼어들 수 있습니다 |
| 그래프 표시 | `서브` | `세션` |
| 끝난 뒤 | 사라집니다 | 터미널이 남아서 이어 시킬 수 있습니다 |
| 시작할 때 아는 것 | 없습니다. 맡긴 말만 압니다 | 없습니다. 맡긴 말만 압니다 |

세션이 직접 하는 노드에서 서브에이전트가 잠깐 뜨기도 합니다. 그때는 카드에 `+서브`가 붙습니다. 노드를 한 쪽은 여전히 그 세션입니다.

## 새 세션이 떴을 때 할 일

AI가 노드를 새 세션에 맡기면 멀티플렉서에 AI 세션이 뜹니다 (`--agent`를 주지 않으면 맡긴 세션과 같은 도구). AI가 정한 곳(터미널 옆 pane 또는 새 tab)에 보이고, 키보드는 사용자가 있던 칸에 그대로 있습니다. 맡긴 세션은 `muwi wait`로 결과를 기다리고, 맡은 세션은 끝나면 `muwi tell`로 알립니다.

### 폴더 신뢰 확인에 답하기

새 세션이 처음 보는 폴더에서 뜨면 "이 폴더를 신뢰하나요?" 확인에서 멈춥니다. AI는 이 확인을 대신 누르지 않습니다.

1. 그래프에서 "세션이 입력을 기다림"이 붙은 카드를 찾으세요. Herdr에서는 에이전트 목록에 "Needs you"도 붙습니다.
2. 그 칸으로 가서 확인을 누르세요.

확인하면 새 세션이 맡은 노드에 붙고, 카드가 "작업 중"으로 바뀝니다. 권한 확인이 뜰 때도 같은 방법으로 답하세요.

### 새 세션 들여다보기

1. 그래프에서 그 노드의 카드를 누르세요.
2. 오른쪽 기록에서 "터미널로 가기"를 누르세요.

그 세션의 pane으로 이동합니다. pane 없이 떠 있는 세션은 그 자리에서 들여다볼 수 있습니다. 기록에는 그 세션에 "맡긴 말"도 나옵니다.

터미널에서는 `muwi peek <노드>`로 그 세션의 화면을 보고, `muwi tell <노드> "<말>"`로 말을 보낼 수 있습니다.

### 끝난 세션 정리하기

끝난 세션은 닫히지 않고 남습니다. 어떻게 판단했는지 다시 볼 수 있습니다. 정리하려면 AI에게 말하거나 직접 실행하세요.

```sh
muwi tidy <작업>
```

끝난 노드를 맡았던 세션의 터미널만 닫습니다. 진행 중인 세션은 닫지 않습니다. muwi가 아는 다른 대화가 그 터미널을 쓰고 있거나, 에이전트가 돌지 않는 터미널(셸만 남았거나 다른 프로그램)도 닫지 않습니다.

세션이 닫혀 멈춘 노드는 `muwi resume <노드>`로 이어 할 수 있습니다. 자세한 것은 [작업 이어서 하기](continue-work.md)에 있습니다.

## 맡기는 방식 정해 주기

원하는 방식이 있으면 시킬 때 말하세요.

```
리뷰는 새 세션에서 해줘. 내가 옆에서 볼게
```

항상 그렇게 하고 싶으면 자신의 skill이나 지침에 적어 두세요. muwi의 지침에는 넣지 않습니다.

## 알아 둘 점

- 새 세션은 터미널 연결(예: `@muwi/herdr`)이 붙어 있고 멀티플렉서의 터미널 안에서 일할 때만 띄울 수 있습니다. 다른 환경에서는 AI가 서브에이전트를 씁니다.
- 새 세션은 계획을 따로 만들지 않습니다. 같은 그래프에 기록합니다. 맡은 일을 나눠야 하면 같은 계획에 노드를 넣습니다.
- 새 세션이 떴던 칸에서 `/clear`를 하고 다른 일을 시키면, 그 세션은 옛 노드에 다시 붙지 않습니다.
- 계획에 적은 방식과 다르게 끝난 노드는 노드의 기록에 계획과 실제로 한 쪽이 나란히 나옵니다 (`계획: 새 세션 · 실제: 직접`). 예를 들어 새 세션으로 하기로 한 노드를 세션이 직접 한 경우입니다. `muwi show`에는 "계획과 다름"이 붙습니다.
