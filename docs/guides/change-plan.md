# 진행 중에 계획 바꾸기

AI가 일하는 도중에 단계를 추가하거나 뺍니다. 바꾼 내용과 이유가 기록에 남아서, 나중에 계획이 왜 달라졌는지 확인할 수 있습니다.

## 말로 바꾸기

바꾸고 싶은 것을 AI에게 말하세요.

```
화면 확인 전에 lint부터 돌려
```

AI가 계획에 노드를 넣고, 그래프가 다시 그려집니다. 작업의 기록에 이렇게 남습니다.

```
계획이 바뀐 기록
  11-22 10:12  사람  +lint  이유: 화면 확인 전에 lint부터 돌리라고 함
```

`사람`은 사용자가 시킨 변경, `AI`는 AI가 스스로 바꾼 변경입니다. `+`는 넣은 노드, `-`는 뺀 노드, `~`는 제목, 순서, 맡는 쪽이 바뀐 노드입니다.

## 노드 빼기

필요 없는 단계는 빼 달라고 하세요.

```
화면이 안 바뀌는 수정이니까 화면 확인은 빼
```

뺀 노드는 그래프에서 사라지지만 기록은 남습니다. 작업의 기록에 "빠진 노드"로 무엇이었는지와 뺀 이유가 나옵니다.

## 명령으로 직접 바꾸기

터미널에서 직접 바꿀 수도 있습니다. 사용자가 바꾼 것임을 남기려면 `--human`을 붙이세요.

```sh
muwi add lint "lint 실행" --after impl --before check --why "화면 확인 전에 lint부터" --human --work <작업>
muwi remove check --why "화면이 바뀌지 않는 수정" --human --work <작업>
```

옵션은 [명령어](../reference/commands.md#계획-바꾸기)에 있습니다.

## 진행 중인 노드가 지켜지는 방식

AI가 계획 전체를 다시 낼 때, 이미 시작했거나 끝난 노드가 새 계획에 빠져 있으면 muwi가 받지 않습니다. 새 세션이 넣고 하고 있는 노드를 다른 세션이 모른 채 지우는 일을 막습니다.

그 노드를 정말 빼려면 `muwi remove`로 이유를 적고 하나씩 뺍니다.

## 알아 둘 점

- 그래프에서 카드를 끌거나 눌러서 계획을 고치는 기능은 없습니다.
- 계획을 바꾸는 것을 막는 기능도 없습니다. AI는 필요하면 계획을 고치고, 그 이유를 남깁니다.
