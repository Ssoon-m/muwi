# 아직 없는 것과 한계

- **Codex**: `muwi setup --codex`로 지침과 사용법 skill을 넣으면 `muwi`로 계획을 적을 수는 있지만 훅이 없습니다. 읽은 skill이 기록되지 않고, 계획 알림도 없습니다.
- **그래프는 Herdr 앱에서만** 보입니다. 다른 환경에서는 `muwi show`로 글만 봅니다.
- **대화가 요약(compact)된 뒤** 앞에서 읽은 skill 내용이 얼마나 남는지는 알 수 없습니다. 요약된 시각만 기록에 남깁니다.
- **그래프에서 직접 고치기**, 작업 지우기·보관 명령은 없습니다. 지우려면 `~/.muwi/<작업>` 폴더를 지웁니다.
- 다른 컴퓨터에서 도는 세션의 기록은 그 컴퓨터의 `~/.muwi`에 남습니다. 그래프 칸은 이 컴퓨터의 기록만 봅니다.
- 단계 순서나 세션 배치를 정해 둔 skill이 설치돼 있으면 AI가 플로우를 스스로 짜지 않고 그 순서를 따릅니다. muwi와 같이 쓸 skill에는 판단 기준만 둡니다.
- skill을 읽고도 무시했는지는 기록으로 알 수 없습니다. 결과물을 봐야 합니다.
- npm 패키지는 없습니다. TypeScript를 Node로 바로 실행하는데, 이 방식은 `node_modules` 안에서 동작하지 않습니다.
- 명령의 출력과 지침은 한국어입니다.
