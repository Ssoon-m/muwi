# 시작하기

muwi를 설치하고, AI에게 일을 하나 맡겨서 그 진행을 그래프로 봅니다. 10분쯤 걸립니다.

이 문서를 마치면 다음을 할 수 있습니다.

- muwi를 설치하고 Herdr 앱 화면에 작업 목록과 그래프 칸을 넣습니다.
- AI가 짠 계획이 그래프에 그려지는 것을 확인합니다.
- 카드를 눌러 노드의 기록을 읽습니다.

## 준비하기

세 가지가 필요합니다.

| 필요한 것 | 확인하는 방법 |
| --- | --- |
| AI 도구 (이 문서는 예로 Claude Code를 씁니다. 다른 도구도 `muwi setup --tool <도구>`로 같습니다) | 터미널에서 그 도구의 버전 확인 (예: `claude --version`) |
| [Herdr 앱](https://herdr.dev) | 앱을 열고, 그 안의 터미널에서 진행합니다 |
| Node 24 이상과 npm | `node -v`, `npm -v` |

Windows에서는 Git for Windows도 필요합니다. AI 도구가 muwi 훅을 Git Bash의 `sh`로 실행합니다. 다른 점은 [Windows에서 쓰기](reference/setup.md#windows에서-쓰기)에 있습니다.

nvm이나 mise로 Node를 골라도 됩니다. Herdr가 띄우는 세션은 셸 설정을 읽지 않지만, muwi가 로그인 셸에 물어 터미널과 같은 Node를 찾습니다. 찾는 방법은 [문제 해결하기](guides/troubleshooting.md#node-24-이상이-필요하다고-나올-때)에 있습니다.

## 1. muwi 설치하기

Herdr 앱의 터미널에서 실행하세요. Herdr 앱에서 그래프로 보려면 `@muwi/herdr-app`을 깝니다 (기록만 쓰는 코어 `@muwi/core`가 같이 깔립니다).

```sh
npm i -g @muwi/herdr-app
```

## 2. AI 도구에 커넥터 넣기

```sh
muwi setup --tool claude     # 쓰는 도구 이름으로 (codex, gemini …). 깔린 AI 도구 전부에 넣으려면 muwi setup --all
```

`muwi setup`이 넣는 것은 이렇습니다.

- 터미널과 그래프 칸이 쓰는 `muwi` 명령 (`~/.local/bin/muwi`, Windows는 `muwi.cmd`도)
- Herdr 앱의 그래프 칸
- 고른 AI 도구의 커넥터: AI에게 주는 지침, 사용법 skill, 진행을 지켜보는 훅. Claude Code라면 훅을 `~/.claude/settings.json`에, 사용법을 `~/.claude/skills/muwi`에 넣습니다 (도구마다 넣는 곳은 [다른 AI 도구에 넣기](reference/setup.md#다른-ai-도구에-넣기)). 고치기 전의 설정은 `settings.json.muwi.bak`으로 남기고, 다른 훅은 건드리지 않습니다.

그다음 그 도구의 세션을 새로 여세요. 훅은 새로 연 세션부터 돕니다.

```sh
claude          # 예: Claude Code. 쓰는 도구를 켜세요 (codex, gemini …)
```

## 3. 화면에 muwi 넣기

`muwi setup`이 화면에 muwi 칸이 있는지 알려 줍니다. 없으면 터미널에서 실행하세요. AI에게 "muwi 화면으로 바꿔줘"라고 해도 됩니다.

```sh
muwi layout
```

화면이 이렇게 바뀝니다.

| 자리 | 바뀐 것 |
| --- | --- |
| 사이드바의 Agents 자리 | 작업 목록. 아직 맡긴 일이 없으면 지금 떠 있는 세션이 "열린 세션"으로 나옵니다 |
| 터미널 아래 | 그래프 칸. 아직 맡긴 일이 없어서 "기록된 작업이 없어요"라고 나옵니다 |

지금 레이아웃을 복제해서 바꾸므로 원래 화면은 그대로 남습니다. 되돌리려면 `muwi layout --remove`를 실행하세요.

화면을 바꾸고 싶지 않으면 `muwi open`을 실행하세요. 그 터미널 아래에 그래프 칸이 열립니다. 이 칸은 연 탭에서만 보입니다.

## 4. 일 맡기기

연습할 저장소에서 AI 도구의 세션을 열고, 파일을 몇 개 고쳐야 하는 일을 시키세요. 명령을 붙이지 않고 평소처럼 말하면 됩니다.

```
formatPrice가 1000 이상이면 천 단위 쉼표를 넣게 해줘. 테스트도 추가해줘.
```

AI가 계획을 짜서 기록하면 그래프 칸에 카드가 나타납니다. 예를 들면 이런 모양입니다.

```
[구현과 테스트 추가] → [테스트 실행] → [리뷰]
```

AI가 일을 진행하면서 카드가 차례로 "작업 중", "끝"으로 바뀝니다. 계획의 모양은 AI가 그 일에 맞게 정하기 때문에 매번 다릅니다.

## 5. 기록 읽기

카드를 하나 누르세요. 오른쪽에 그 노드의 기록이 나옵니다.

- 누가 했는지: 세션이 직접 했는지, 서브에이전트나 새 세션이 했는지
- 걸린 시간과 결과 한 줄
- 읽은 skill: 그 노드를 하는 동안 AI가 읽은 skill

터미널에서 글로 보려면 이렇게 하세요.

```sh
muwi status          # 작업 목록
muwi show <작업>      # 작업 하나의 기록
```

## 자주 겪는 문제

| 증상 | 해결 방법 |
| --- | --- |
| 그래프 칸에 "기록을 읽지 못했어요"가 나옵니다 | 2단계의 `muwi setup`을 실행하세요 |
| 일을 시켰는데 카드가 생기지 않습니다 | 커넥터를 넣은 뒤에 연 세션인지 확인하세요. 오타 수정처럼 작은 일은 AI가 계획 없이 진행합니다 |
| "Node 24 이상이 필요해요"가 나옵니다 | [문제 해결하기](guides/troubleshooting.md#node-24-이상이-필요하다고-나올-때)를 보세요 |

다른 증상은 [문제 해결하기](guides/troubleshooting.md)에 있습니다.
