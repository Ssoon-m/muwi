# 시작하기

muwi를 설치하고, AI에게 일을 하나 맡겨서 그 진행을 그래프로 봅니다. 10분쯤 걸립니다.

이 문서를 마치면 다음을 할 수 있습니다.

- muwi를 설치하고 Herdr 앱에 그래프 칸을 엽니다.
- AI가 짠 계획이 그래프에 그려지는 것을 확인합니다.
- 카드를 눌러 노드의 기록을 읽습니다.

## 준비하기

세 가지가 필요합니다.

| 필요한 것 | 확인하는 방법 |
| --- | --- |
| Claude Code | 터미널에서 `claude --version` |
| Herdr 앱 | 앱을 열고, 그 안의 터미널에서 진행합니다 |
| Node 24 이상 | `node -v`, 그리고 `hc exec 'node -v'` |

Node는 두 곳에서 모두 24 이상이어야 합니다. `hc exec 'node -v'`는 Herdr가 띄우는 프로그램에 잡히는 Node를 보여 줍니다. nvm처럼 셸 설정으로 Node를 고르면 이 값이 터미널과 다를 수 있습니다. 낮게 나오면 [문제 해결하기](guides/troubleshooting.md#node-24-이상이-필요하다고-나올-때)를 보세요.

## 1. 플러그인 설치하기

Herdr 앱의 터미널에서 실행하세요.

```sh
claude plugin install muwi --marketplace Ssoon-m/muwi
```

플러그인은 `muwi` 명령, 진행을 기록하는 훅, AI에게 주는 지침을 Claude Code에 넣습니다. 사용자의 `settings.json`과 `CLAUDE.md`는 고치지 않습니다.

## 2. 그래프 칸 설치하기

Claude Code 세션을 새로 여세요. 플러그인은 새로 연 세션부터 적용됩니다.

```sh
claude
```

세션 안에서 이렇게 시키세요.

```
muwi setup 실행해줘
```

플러그인의 `muwi` 명령은 Claude Code 안에서만 보입니다. `muwi setup`은 터미널에서도 쓸 수 있는 `muwi` 명령(`~/.local/bin/muwi`)과 Herdr 앱의 그래프 칸을 설치합니다.

## 3. 그래프 칸 열기

세션 안에서 이렇게 시키세요.

```
muwi open 실행해줘
```

터미널에서 직접 `muwi open`을 실행해도 됩니다. 그 터미널 아래에 그래프 칸이 열립니다. 아직 맡긴 일이 없어서 "기록된 작업이 없어요"라고 나옵니다. 오른쪽에 열려면 `muwi open --right`를 쓰세요.

## 4. 일 맡기기

연습할 저장소에서 Claude Code 세션을 열고, 파일을 몇 개 고쳐야 하는 일을 시키세요. 명령을 붙이지 않고 평소처럼 말하면 됩니다.

```
formatPrice가 1000 이상이면 천 단위 쉼표를 넣게 해줘. 테스트도 추가해줘.
```

AI가 계획을 짜서 기록하면 그래프 칸에 카드가 나타납니다. 예를 들면 이런 모양입니다.

```
[구현과 테스트 추가] → [테스트 실행] → [리뷰]
```

AI가 일을 진행하면서 카드가 차례로 "작업 중", "끝"으로 바뀝니다. 계획의 모양은 AI가 그 일에 맞게 정하기 때문에 매번 다릅니다.

## 5. 기록 읽기

카드를 하나 누르세요. 오른쪽에 그 노드의 기록이 나옵니다.

- 누가 했는지: 세션이 직접 했는지, 서브에이전트나 새 세션이 했는지
- 걸린 시간과 결과 한 줄
- 읽은 skill: 그 노드를 하는 동안 AI가 읽은 skill

터미널에서 글로 보려면 이렇게 하세요.

```sh
muwi status          # 작업 목록
muwi show <작업>      # 작업 하나의 기록
```

## 자주 겪는 문제

| 증상 | 해결 방법 |
| --- | --- |
| 그래프 칸에 "기록을 읽지 못했어요"가 나옵니다 | 2단계의 `muwi setup`을 실행하세요 |
| 일을 시켰는데 카드가 생기지 않습니다 | 플러그인을 설치한 뒤에 연 세션인지 확인하세요. 오타 수정처럼 작은 일은 AI가 계획 없이 진행합니다 |
| "Node 24 이상이 필요해요"가 나옵니다 | [문제 해결하기](guides/troubleshooting.md#node-24-이상이-필요하다고-나올-때)를 보세요 |

다른 증상은 [문제 해결하기](guides/troubleshooting.md)에 있습니다.
