# 제한 사항

muwi가 하지 못하는 것과, 기록을 읽을 때 조심할 점입니다. 각 항목의 해결 방법은 [문제 해결하기](../guides/troubleshooting.md)에 있습니다.

## 환경

- **Claude Code에서 씁니다.** Codex에는 `muwi setup --codex`로 지침만 넣을 수 있습니다. 훅이 없어서 읽은 skill이 기록되지 않고 계획 알림도 없습니다.
- **그래프 보기, 새 세션 띄우기, 닫힌 세션 알아채기는 Herdr 앱 안에서만 됩니다.** 다른 환경에서는 `muwi status`와 `muwi show`로 글만 봅니다.
- **Node 24 이상이 필요합니다.** npm 패키지는 없습니다.
- **Windows는 CI에서 확인한 만큼만 보장합니다.** 시험 전체, Git Bash로 훅 실행, PowerShell·cmd의 `muwi.cmd`를 확인합니다. Windows용 Herdr 앱의 그래프 칸과 실제 Claude Code 세션의 훅 호출은 확인하지 못했습니다. Git for Windows가 없으면 훅이 돌지 않습니다.
- 그래프 칸은 이 컴퓨터의 기록만 봅니다. 다른 컴퓨터에서 실행한 세션의 기록은 그 컴퓨터에 남습니다.
- 명령의 출력과 AI에게 주는 지침은 한국어입니다.

## 기록의 정확도

- **AI가 시작을 제때 기록해야 합니다.** AI가 일을 마친 뒤에 시작과 끝을 함께 기록하면 그 노드는 "기록 없음"으로 남습니다. 틀린 내용을 보여 주지는 않지만 알 수 있는 것이 줄어듭니다.
- **하던 작업을 끝내지 않고 다른 일을 시키면 알아채지 못합니다.** AI가 새 작업으로 적지 않으면 그 일의 기록이 하던 노드에 붙습니다.
- 같은 세션이 노드 여러 개를 동시에 하면, 그동안 읽은 skill은 가장 늦게 시작한 노드에 "확실하지 않음"으로 붙습니다.
- 세션이 시작해 둔 노드에서 서브에이전트가 일한 경우, 서브에이전트가 얼마나 했는지는 알 수 없습니다. 계획에 서브에이전트로 하기로 적은 노드만 `서브`로 표시하고, 나머지는 `+서브`(도움)로 표시합니다.
- 서브에이전트에게 준 말은 기록에 남지 않습니다. 새 세션에 맡긴 말만 남습니다.

## 읽은 skill

- AI가 Skill 도구로 부른 것과 `SKILL.md` 파일을 읽은 것만 기록됩니다. 다른 방법으로 들어온 skill(사용자가 직접 입력한 `/skill이름` 등)은 기록되지 않을 수 있습니다.
- skill을 읽고도 따르지 않았는지, 읽지 않았지만 맞게 했는지는 기록에 나오지 않습니다.
- 대화가 요약(compact)된 뒤 앞에서 읽은 skill 내용이 얼마나 남는지는 알 수 없습니다. 요약된 시각만 기록합니다.
- 같은 skill을 Skill 도구로도 부르고 파일로도 읽으면 이름이 달라서 두 줄로 나올 수 있습니다.

## 계획 알림

- 파일 수정 도구(Edit, Write)를 쓸 때만 동작합니다. 셸 명령으로 고치는 것은 잡지 못합니다.
- 서브에이전트는 세션과 같은 확인을 씁니다. 서브에이전트가 `muwi skip`을 실행하면 그 요청 동안 세션 전체에 적용됩니다.
- push 전에 묻는 기능(`guard`)은 기본으로 꺼져 있습니다.

## 그래프

- 그래프에서 계획을 직접 고칠 수 없습니다. AI에게 말하거나 명령을 씁니다.
- 새 세션 안의 세부 단계는 그 세션이 노드를 추가했을 때만 보입니다.
- 계획 하나에 노드는 60개까지입니다.
- 오래된 작업은 목록에서 접어 둘 뿐 지우지 않습니다. 지우려면 `~/.muwi/<작업>` 폴더를 지우세요.
- 순서를 정해 둔 skill이 설치돼 있으면 AI가 계획을 스스로 짜지 않고 그 순서를 따릅니다.
